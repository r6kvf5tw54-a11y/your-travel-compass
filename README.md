# Your Travel Compass

Build a premium travel discovery app called Tourist Adventures.

Core idea: personalized discovery of the best places in any country based on user tastes.

Main flow:

Onboarding:

Ask user where they are traveling from

Ask destination country/city

Ask preferences via visual cards:

Food (cheese, salads, meat, seafood, vegan, etc)

Categories: Restaurants, Hotels, Spa, Gyms, Attractions

Allow multiple selections

After onboarding:
Show curated recommendations:

Restaurants

Hotels

Spa

Sports / Gyms

Each place card includes:

Photos

Short description

Tags (e.g. “halloumi”, “salad bar”, “buffet”, “family friendly”)

Price range

Distance

Rating

“Why we recommend this” (based on selected preferences)

Filtering:

By food type

By category

By distance

By rating

Search bar at top.

Favorites:

User can save places.

Monetization:

Free tier: limited recommendations

Premium subscription unlocks:

Full listings

Advanced filters

Offline access

“Best of city” curated packs

Admin panel:

Add/edit places

Upload photos

Assign tags

Mark premium locations

Tech:

Mobile-first responsive UI

Map view integration

User accounts

Subscription via Stripe

Clean modern design, Apple-like minimalism

Tone:
Ultra-premium travel assistant.
Simple for kids, powerful for adults.

Goal:
Help travelers instantly find places they will love without scrolling Google or TripAdvisor.
